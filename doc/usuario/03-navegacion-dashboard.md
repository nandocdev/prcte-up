## ⚡ Atajos de Teclado

### **⌨️ Atajos Globales**

```
NAVEGACIÓN RÁPIDA:
- Alt + H         → Ir a Dashboard/Home
- Alt + N         → Nuevo trabajo
- Alt + S         → Búsqueda rápida
- Alt + T         → Mis trabajos
- Alt + R         → Reportes
- Ctrl + /        → Mostrar atajos
- Esc             → Cerrar modal/menú
```

### **🎯 Atajos Específicos por Sección**

#### **📝 En Formularios**
```
- Ctrl + S        → Guardar borrador
- Ctrl + Enter    → Enviar/Siguiente
- Tab             → Siguiente campo
- Shift + Tab     → Campo anterior
- Ctrl + Z        → Deshacer
- Ctrl + Y        → Rehacer
```

#### **📊 En Listas y Tablas**
```
- ↑ ↓             → Navegar filas
- Enter           → Abrir elemento
- Space           → Seleccionar/deseleccionar
- Ctrl + A        → Seleccionar todo
- Delete          → Eliminar seleccionado
```

## 🎯 Optimización de Productividad

### **⚡ Flujos de Trabajo Optimizados**

#### **🚀 Para Crear un Trabajo Nuevo**
```
FLUJO RÁPIDO (3 clics):
1. 🏠 Dashboard → ➕ "Nuevo Trabajo"
2. 🎯 Seleccionar tipo → "Continuar"
3. 📝 Autocompletado → "Guardar borrador"
```

#### **🔍 Para Revisar Trabajos Pendientes**
```
FLUJO EFICIENTE:
1. 🔔 Notificación → "Ver pendientes"
2. 📋 Lista filtrada → Seleccionar trabajo
3. 👁️ Vista rápida → Aprobar/Observaciones
```

### **📊 Métricas de Productividad**

#### **⏱️ Tiempo Promedio por Acción**
```
BENCHMARKS DEL SISTEMA:
```
