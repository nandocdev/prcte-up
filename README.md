# PRCTE-UP

> **Institutional project — Universidad de Panamá.**

PRCTE-UP is an extension-management system developed for an institutional context at the Universidad de Panamá.

This repository is kept public as a technical reference and portfolio evidence of work on a real institutional system. It is not a NandocDev commercial product.

## Context

The system covers workflows related to university extension activities, administration, roles, documentation and operational processes.
